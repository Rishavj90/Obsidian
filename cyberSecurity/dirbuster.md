# Offensive Security
- Attack systems to find flaws

# dirbuster
`dirbuster` can access all the files and directories on a server
```
dirb <site>
```
[dirb](https://www.kali.org/tools/dirbuster/) 


# Defensive security
- It focuses on detecting and investigating attacks, and responding before damage occurs.
- Unlike offensive security, you do not attack systems, instead, you monitor and protect them.
